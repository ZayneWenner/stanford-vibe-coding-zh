Claude Code 概览

Claude Code 是一款智能体式（agentic）编程工具，它能阅读你的代码库、编辑文件、运行命令，并与你的开发工具集成。它可在终端、IDE、桌面应用和浏览器中使用。

Claude Code 是一个由 AI 驱动的编程助手，能帮你构建功能、修复缺陷并自动化开发任务。它理解你的整个代码库，并能跨多个文件和工具完成任务。

开始使用

选择你的环境来开始。多数使用场景需要 Claude 订阅 或 Anthropic Console 账户。终端 CLI 和 VS Code 也支持第三方提供商。

可用环境：终端（Terminal）、VS Code、桌面应用（Desktop app）、Web、JetBrains。

终端（Terminal）——用于在终端中直接操作 Claude Code 的全功能 CLI。你可以编辑文件、运行命令，并用命令行管理整个项目。要安装 Claude Code，可使用以下方法之一：

  • 原生安装（Native Install，推荐）
  • Homebrew
  • WinGet

macOS、Linux、WSL：

curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell：

irm https://claude.ai/install.ps1 | iex

Windows CMD：

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

如果你看到 The token '&&' is not a valid statement separator，说明你处于 PowerShell 而非 CMD 中。请改用上面的 PowerShell 命令。在 PowerShell 下你的提示符会显示 PS C:\。Windows 需要 Git for Windows，如果尚未安装请先安装。

原生安装会在后台自动更新，使你始终使用最新版本。

brew install --cask claude-code

Homebrew 安装不会自动更新。请定期运行 brew upgrade claude-code 以获取最新功能和安全修复。

winget install Anthropic.ClaudeCode

WinGet 安装不会自动更新。请定期运行 winget upgrade Anthropic.ClaudeCode 以获取最新功能和安全修复。

随后在任意项目中启动 Claude Code：

cd your-project
claude

首次使用时会提示你登录。就这么简单！继续阅读快速入门 → 有关安装选项、手动更新或卸载说明，请参阅高级设置。如果遇到问题，请访问故障排查。

VS Code——VS Code 扩展在编辑器内提供行内 diff、@提及、计划审查与会话历史。

  • 为 VS Code 安装
  • 为 Cursor 安装

或者在扩展视图（Mac 上为 Cmd+Shift+X，Windows/Linux 上为 Ctrl+Shift+X）中搜索 “Claude Code”。安装后打开命令面板（Cmd+Shift+P / Ctrl+Shift+P），输入 “Claude Code”，并选择 Open in New Tab。开始使用 VS Code →

桌面应用（Desktop app）——一个在你的 IDE 或终端之外运行 Claude Code 的独立应用。可视化审查 diff、并排运行多个会话、安排周期性任务，并启动云端会话。下载并安装：

  • macOS（Intel 与 Apple Silicon）
  • Windows（x64）
  • Windows ARM64（仅远程会话）

安装后启动 Claude，登录，并点击 Code 标签页开始编码。需要付费订阅。了解更多关于桌面应用 →

Web——无需本地配置即可在浏览器中运行 Claude Code。启动长时间运行的任务，完成后回来查看；处理你本地没有的代码仓库；或并行运行多个任务。适用于桌面浏览器和 Claude iOS 应用。在 claude.ai/code 开始编码。在 Web 上开始使用 →

JetBrains——适用于 IntelliJ IDEA、PyCharm、WebStorm 及其他 JetBrains IDE 的插件，支持交互式 diff 查看与选区上下文共享。从 JetBrains Marketplace 安装 Claude Code 插件 并重启你的 IDE。开始使用 JetBrains →

你能做什么

以下是你可以使用 Claude Code 的一些方式：

自动化你一直拖延的工作
Claude Code 处理那些占用你一天时间的琐碎任务：为未经测试的代码编写测试、修复整个项目的 lint 错误、解决合并冲突、更新依赖项，以及撰写发布说明。

claude "write tests for the auth module, run them, and fix any failures"

构建功能与修复缺陷
用自然语言描述你想要的。Claude Code 规划方案，跨多个文件编写代码，并验证其是否可用。对于缺陷，粘贴错误信息或描述症状。Claude Code 会追踪穿过代码库的问题，找出根因，并实现修复。更多示例请参阅常见工作流。

创建提交与拉取请求
Claude Code 直接与 git 协作。它暂存改动、撰写提交信息、创建分支，并打开拉取请求（PR）。

claude "commit my changes with a descriptive message"

在 CI 中，你可以用 GitHub Actions 或 GitLab CI/CD 自动化代码审查与问题分诊。

用 MCP 连接你的工具
模型上下文协议（MCP） 是将 AI 工具连接到外部数据源的开放标准。借助 MCP，Claude Code 可以读取你在 Google Drive 中的设计文档、更新 Jira 中的工单、从 Slack 拉取数据，或使用你自己的自定义工具。

用指令、技能（skills）与钩子（hooks）进行定制
CLAUDE.md 是你添加到项目根目录的一个 markdown 文件，Claude Code 会在每次会话开始时读取它。用它来设定编码规范、架构决策、偏好的库以及审查清单。Claude 还会在工作时构建自动记忆（auto memory），跨会话保存诸如构建命令与调试心得等学习内容，无需你手动书写任何内容。创建自定义命令 来打包团队可共享的重复性工作流，例如 /review-pr 或 /deploy-staging。钩子（Hooks） 让你在 Claude Code 的动作之前或之后运行 shell 命令，例如在每次文件编辑后自动格式化，或在提交前运行 lint。

运行智能体团队并构建自定义智能体
生成多个 Claude Code 子智能体（sub-agents），让它们同时处理任务的不同部分。一个主导智能体（lead agent）负责协调工作、分配子任务并合并结果。对于完全自定义的工作流，Agent SDK 让你可以构建由 Claude Code 的工具与能力驱动的自定义智能体，并完全控制编排、工具访问与权限。

用 CLI 进行管道化、脚本化与自动化
Claude Code 是可组合的，并遵循 Unix 哲学。将日志管道输入它、在 CI 中运行它，或将其与其他工具串联：

# 分析最近的日志输出
tail -200 app.log | claude -p "Slack me if you see any anomalies"

# 在 CI 中自动化翻译
claude -p "translate new strings into French and raise a PR for review"

# 跨文件批量操作
git diff main --name-only | claude -p "review these changed files for security issues"

有关完整的命令与标志集，请参阅 CLI 参考。

安排周期性任务
按日程运行 Claude，以自动化重复性的工作：早晨的 PR 审查、夜间的 CI 失败分析、每周的依赖审计，或在 PR 合并后同步文档。

  • 云端周期性任务 运行在 Anthropic 管理的基础设施上，因此即使你的电脑关机也会持续运行。可从 Web、桌面应用，或在 CLI 中运行 /schedule 来创建。
  • 桌面周期性任务 运行在你的机器上，可直接访问你的本地文件与工具。
  • /loop 在一个 CLI 会话内重复某个提示，用于快速轮询。

随处工作
会话不绑定于单一界面。随着上下文变化，你可以在不同环境间移动工作：

  • 离开办公桌，用手机或任意浏览器通过 远程控制（Remote Control） 继续工作。
  • 用手机通过 Dispatch 发送一个任务，并打开它创建的桌面会话。
  • 在 Web 或 iOS 应用 上启动长时间运行的任务，然后用 claude --teleport 将其拉入终端。
  • 用 /desktop 将终端会话交给 桌面应用，进行可视化 diff 审查。
  • 从团队聊天路由任务：在 Slack 中 @Claude 并附上缺陷报告，即可拿回一个拉取请求。
