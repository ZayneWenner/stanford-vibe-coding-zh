Warp 与 Oz 入门

开始使用 Warp（智能体式开发环境，Agentic Development Environment）与 Oz（面向云端智能体的编排平台）。

Warp 是一个智能体式开发环境——它将现代化的终端与强大的智能体（Agent）相结合，帮助你构建、测试、部署并调试代码。Warp 的 AI 能力由 Oz 驱动，后者是面向云端智能体的编排平台。

Warp 将现代化的终端与 Oz（面向云端智能体的编排平台）结合在一起。

Warp

Warp 是你的工作所在——一个为与智能体协作编程而打造的快速、现代化终端。

核心能力：

  • 智能体形态（Agent Modality）：在用于执行命令的简洁终端视图，与用于多轮智能体工作流的专用对话视图之间自由切换。
  • 现代化终端体验：光标移动、基于区块的导航、多行编辑、语法高亮以及丰富的自动补全。底层使用 Rust 编写，性能出色。
  • 代码编辑器：文件树、支持 LSP 的代码编辑器，以及交互式代码审查体验。
  • 编程智能体集成：提供语音输入、@ 选择（用于与基于终端的镜像协作）等功能。兼容 Oz，也可对接 Claude Code、Codex 等智能体。

深入探索 Warp 的核心功能

Oz：面向云端智能体的编排平台

Oz 是面向云端智能体的编排平台，为 Warp 的全部智能特性提供支撑。Oz 旨在大规模地协调智能体——理解你的代码仓库、自主执行任务，并适配你的工作流。Oz 在设计上采用多模型架构，让你可以灵活地为每个任务挑选最合适的大语言模型（LLM）。

Oz 以两种模式运行：

本地智能体

直接在 Warp 应用中运行，提供实时的交互式编程辅助。

  • 在代码仓库范围内编写与重构代码
  • 排查问题并修复错误
  • 运行命令并解读结果
  • 规划并执行多步骤任务

本地智能体让你始终掌控全局。你可以审阅改动、在任务进行中引导智能体，并在动作执行前进行审批。

→ 开始使用本地智能体

云端智能体

Oz 云端智能体在 Warp 的基础设施（或你自己的基础设施）上于后台运行，实现大规模的自动化。

  • 触发器（Triggers）：对来自 Slack、Linear、GitHub 或自定义 Webhook 的事件作出响应。
  • 定时任务（Schedules）：运行周期性任务，例如依赖更新或死代码清理。
  • 并行能力（Parallelism）：跨越多个代码仓库或任务并发运行大量智能体。
  • 可观测性（Observability）：每一次运行都被追踪、可审计，并可与团队共享。

云端智能体非常适合那些不需要你立即关注的工作，例如拉取请求（PR）审查、问题分诊、日常维护，以及由集成驱动的工作流。

它们如何协同工作

Warp 与 Oz 在本地与云端开发之间提供统一的体验：

  • 同一套智能体，无处不在：无论你是在 Warp 中交互式地工作，还是在云端运行智能体，你使用的都是同一套底层智能体能力。
  • 无缝交接：在云端启动任务，当你需要亲自动手控制时，可在 Warp 中无缝接管本地执行，而不会丢失进度或上下文。
  • 共享上下文：Warp Drive、Rules 与 MCP 服务器在本地与云端智能体之间通用，因此团队的知识与工具始终可用。
  • 团队协作：共享智能体会话、审阅智能体的动作，并引导正在运行的任务——无论任务最初由谁发起。

多模型支持

Oz 在设计上采用多模型架构。你可以从一组精选的顶尖模型中，选择自己偏好的大语言模型（LLM）。

隐私与安全

Warp 符合 SOC 2 合规要求，并与所有签约的大语言模型（LLM）供应商执行零数据保留（Zero Data Retention）策略。客户的 AI 数据不会被保留、存储，也不会被用于模型训练。

Warp 的 AI 功能可在「设置 > AI」中全局关闭。
